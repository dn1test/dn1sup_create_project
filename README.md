# DN1SUP Create Project

Расширение SketchUp для создания и оформления мебельных проектов: структура папок,
YAML-карточка проекта с историей, картинки и документы. Переписано со старого
CLI-генератора (`_old/create_project.rb`) на полноценное расширение с HTML-интерфейсом
на Vue 3.

## Возможности

- **Создать** — мастер из старого генератора: коммерческий или бытовой заказ,
  данные заказчика, список проектов (место + мебель из настраиваемых списков),
  предпросмотр имён папок/файлов, артикулы `CF#YYMMDDHHMMSS` / `HF#YYMMDDHHMMSSNN`.
  Бытовые проекты группируются в папку заказа «Заказчик ~ Адрес».
- **Проекты** — реестр созданных проектов и подключение существующих папок:
  описание проекта, картинки и документы (копируются в проект), описание к каждому
  файлу, создание подпапок, история изменений, открытие папки/файла в Проводнике.
- **Настройки** — вся структура настраивается: подпапки проекта, шаблоны имён
  с плейсхолдерами `{articul} {customer} {company} {address} {place} {product} {timestamp}`,
  префиксы артикулов, списки мест и мебели, расширения файлов. Хранятся в YAML.

## Где что лежит

| Что | Где |
|---|---|
| Настройки структуры | `%APPDATA%\SketchUp\SketchUp 2026\dn1sup_create_project\settings.yaml` |
| Реестр проектов | там же, `projects.yaml` (только пути) |
| Карточка проекта | YAML внутри самого проекта (`<Артикул>.yaml`, формат старого генератора + `description` и `files`) |

Карточка — источник истины: реестр хранит пути, всё остальное читается из проекта,
поэтому зарегистрировать можно и чужую папку, а карточки старого формата читаются.

## Структура проекта на диске

```
Артикул ~ Заказчик ~ Компания ~ Адрес, Место ~ Продукт/
├── Артикул ~ Компания ~ Место ~ Продукт.skp      (копия data/template.skp)
├── Артикул ~ Компания ~ Место ~ Продукт.pur
├── Артикул.yaml                                   (карточка + история)
├── _замер_задание/ … _проект/ _изображения/ _документы/
```

Состав подпапок, имена файлов и папок — всё из настроек.

## Разработка

```
frontend/    Vue 3 + Vite + Tailwind (single-file сборка)
└── npm run build   → dn1sup_create_project/dn1sup_create_project/ui/index.html

dn1sup_create_project/   dev-корень (для установки в Plugins целиком)
└── dn1sup_create_project/
    ├── main.rb dialog.rb settings.rb generator.rb
    ├── projects_store.rb files.rb win_shell.rb dev_updater.rb
    ├── data/  шаблоны template.skp / template.pur
    ├── ui/    собранный интерфейс
    └── test/  ruby test/run_all.rb   (или ext_test внутри SketchUp)
```

Цикл: правка frontend → `npm run build` → копирование в Plugins
(`ruby update_from_dev.rb`, меню «Обновить из dev-папки» или MCP `ext_install`+`ext_reload`).

Меню: **Extensions → DN1SUP → Create Project**. Тулбар: DN1SUP Create Project.

## Тесты

```bash
ruby dn1sup_create_project/dn1sup_create_project/test/run_all.rb   # локально
```
или через MCP `ext_test` внутри SketchUp (19+ тестов: артикулы, шаблоны имён,
санитизация, создание структуры, файлы, реестр, настройки).

## Добавление файлов в диалоге

Окно открывается с `use_file_input: true` — `<input type="file" multiple>` возвращает
полные локальные пути, файлы копируются в подпапки проекта. Если мультивыбор не
сработал (старые версии SketchUp) — файлы можно добавлять по одному.
