# DN1Sup Create Project

Расширение SketchUp для создания и оформления мебельных проектов: структура папок,
YAML-карточка проекта с историей, картинки и документы. HTML-интерфейс на Vue 3.

## Возможности

- **Вопрос о типе при открытии** — «Коммерческий проект» или «Бытовой проект»;
  тип можно сменить в любой момент.
- **Создать** — слева проекты-вкладки (каждая вкладка — отдельный проект:
  Место/Комната + Продукт + файлы), справа карточка заказчика (имя, фирма — для
  коммерческих, телефон, почта, адрес установки) и предпросмотр структуры.
- **Добавить файлы** — несколько файлов за раз в именованную папку внутри проекта
  (можно несколько папок), с превью и именами файлов прямо в интерфейсе.
- **Настройки** — директория проектов (с кнопкой «Выбрать»), шаблоны папок для
  бытового и коммерческого проекта (папка заказа 1-го уровня и папки проектов
  2-го уровня), шаблоны template.skp/template.pur (кнопка «Добавить шаблон»
  копирует выбранный файл в расширение) и имена файлов проекта,
  списки мест и мебели, расширения файлов. Хранятся в YAML.
- **Справка** — описание расширения и пошаговая инструкция: как создать проект,
  что появляется на диске, плейсхолдеры шаблонов.

## Где что лежит

| Что | Где |
|---|---|
| Настройки структуры | `%APPDATA%\SketchUp\SketchUp 2026\dn1sup_create_project\settings.yaml` |
| Реестр проектов | там же, `projects.yaml` (только пути) |
| Карточка проекта | YAML внутри самого проекта (`<Место>.yaml` по шаблону, карточка + история) |

Карточка — источник истины: реестр хранит пути, всё остальное читается из проекта,
поэтому зарегистрировать можно и чужую папку.

## Структура проекта на диске

```
корень проектов/
└── Заказчик ~ Компания ~ Адрес/            (1 уровень — папка заказа)
    ├── Место ~ Продукт/                    (2 уровень — папка проекта)
    │   ├── Место ~ Продукт.skp             (копия template.skp)
    │   ├── Место.pur                       (копия template.pur)
    │   ├── Место.yaml                      (карточка + история)
    │   └── <имена папок из «Добавить файлы»>/файлы
    └── Место ~ Продукт/ …
```

Бытовой заказ: папка заказа `Заказчик ~ Адрес`, папки проектов `{Место}`,
файл `.skp` — `{Место} ~ {Продукт}.skp`, `.pur` и карточка — `{Место}`.
Все имена — шаблоны в настройках (плейсхолдеры
`{customer} {company} {address} {phone} {email} {place} {product}`).
Если папка проекта с таким именем уже существует, к имени добавляется счётчик:
«Кухня (2)», «Кухня (3)»… Служебные подпапки не создаются автоматически (v3 настроек).

## Разработка

```
frontend/    Vue 3 + Vite + Tailwind (single-file сборка)
└── npm run build   → dn1sup_create_project/dn1sup_create_project/ui/index.html

dn1sup_create_project/   dev-корень (для установки в Plugins целиком)
└── dn1sup_create_project/
    ├── main.rb dialog.rb settings.rb generator.rb
    ├── projects_store.rb files.rb win_shell.rb dev_updater.rb
    ├── data/  шаблоны template.skp / template.pur
    ├── ui/    собранный интерфейс
    └── test/  ruby test/run_all.rb   (или ext_test внутри SketchUp)
```

Цикл: правка frontend → `npm run build` → копирование в Plugins
(`ruby update_from_dev.rb`, меню «Обновить из dev-папки» или MCP `ext_install`+`ext_reload`).

Меню: **Extensions → DN1Sup → Create Project**. Тулбар: DN1Sup Create Project.

## Тесты

```bash
ruby dn1sup_create_project/dn1sup_create_project/test/run_all.rb   # локально
```
или через MCP `ext_test` внутри SketchUp (25 тестов: шаблоны имён и папок,
санитизация, создание структуры «заказ → проект», файловые группы, файлы,
реестр, настройки и миграция v2 → v3).

## Добавление файлов в диалоге

Окно открывается с `use_file_input: true` — `<input type="file" multiple>` возвращает
полные локальные пути, файлы копируются в проект. Превью изображений строится в
интерфейсе (FileReader); для остальных файлов показывается иконка по расширению.
Если мультивыбор не сработал (старые версии SketchUp) — файлы можно добавлять по одному.
