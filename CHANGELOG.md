# Changelog — DN1Sup Create Project

Все заметные изменения проекта документируются в этом файле.

## Правила версионирования

Версия формата `X.Y.Z`:

- **X (первая цифра)** — изменяется **только по прямому запросу пользователя**.
- **Y (вторая цифра)** — большие изменения: новые функции, переработка интерфейса, смена архитектуры.
- **Z (третья цифра)** — мелкие недочёты: исправления ошибок, косметика, мелкие правки сборки.

Релизы публикуются тегом `vX.Y.Z` — CI собирает `.rbz` и создаёт GitHub Release автоматически.

## [0.5.8] — 2026-10-26

### DN1Sup Create Project (v0.5.8)
- **Отдельный тулбар всегда.** Удалена зависимость от общей панели DN1Sup:
  тулбар расширения создаётся всегда, без проверки параметра
  «Показывать отдельные тулбары расширений» в менеджере.

## [0.5.7] — 2026-10-18

### DN1Sup Create Project (v0.5.7)
- **Тулбар не создаётся, когда работает общая панель DN1Sup.** Пока в
  менеджере выключен параметр «Показывать отдельные тулбары расширений»
  (по умолчанию), свой тулбар не создаётся — его нет и в списке панелей
  SketchUp (View → Toolbars). Кнопка «Создать проект» остаётся на общей
  панели и в меню DN1Sup. Заодно выровнена версия в MANIFEST
  (0.5.5 → 0.5.7; в 0.5.6 подняли только лоадер).

## [0.5.6] — 2026-10-17

### DN1Sup Create Project (v0.5.6)
- **Обновление — только из GitHub.** Кнопки проверки и фоновая проверка при
  старте переведены с `check_local_first!` на `check!`; `dev_dir` удалён из
  манифеста. Копия общего апдейтера обновлена до v5 (единая копия для всех
  расширений DN1Sup: локальные источники удалены, для менеджеров старых
  версий оставлены заглушки совместимости, status_cb-прогресс сохранён).
## [0.5.5] — 2026-10-16

### DN1Sup Create Project (v0.5.5)

## [0.5.4] — 2026-10-16

### DN1Sup Create Project (v0.5.4)
- **Фирменный знак тулбара DN1Sup** — единый стиль каталога Extension

## [0.5.3] — 2026-10-16

### Fixed
- `update_from_dev.rb` говорил с мостом `dn1sup_mcp2` по HTTP POST `/eval`,
  а мост понимает только TCP newline-JSON — всегда врал «мост не запущен».
  Hot Reload переписан на `Socket.tcp` + `{"cmd":"eval"}`.
- `test/run_all.rb` молча исключал `main_test.rb` (4 теста не исполнялись) —
  теперь грузится первым; в `main_test.rb` убран протухший хардкод версии,
  проверка сверяется с регистратором.

## [0.5.1] — 2026-10-16

- Убран переходный маркер `.sketchup_dev.json` из `Dn1sup::Updater.dev_source?`
  (период миграции со старых `_dev`-установок завершён); self-update рабочей
  копии определяется только по пути загрузки (вне папки Plugins SketchUp).

## [0.5.0] — 2026-10-15

- Удалён функционал dev/prod (второй id `dn1sup_create_project_dev`): удалены
  `DEV_BUILD`, поле `dev_build` в состоянии диалога и бейдж DEV в шапке.
  Разработка — рабочая копия под тем же id («Обновить из рабочей копии» /
  reload); self-update рабочей копии отключён по пути загрузки
  (`Dn1sup::Updater.dev_source?`); файлы `.sketchup_dev.json` удалены.
- Единый апдейтер `Dn1sup::Updater` v3: кнопка проверки обновлений в шапке
  диалога — сначала локальная папка сборки, затем GitHub Releases; dev-кнопки
  обновления и hot reload из рабочей копии убраны.

## [0.4.1] — 2026-10-09

### Changed
- Обновлён общий `dn1sup_updater.rb` (из репозитория Extension Store): обновления распознаются не только по номеру версии, но и по дате публикации релиза. Переизданный релиз без бампа версии или смена схемы нумерации теперь тоже предлагают установку — по дате установки текущей сборки (пишется при установке через апдейтер/Store).

## [0.4.0] — 2026-10-09

### Added
- Самообновление через GitHub Releases независимо от Extension Store: фоновая проверка раз в сутки (через 15 с после старта, throttle 24 ч) и пункты меню «Проверить обновления сейчас» / «Страница релизов на GitHub».
- Корневой `registry.json` с метаданными расширения — источник для каталога Extension Store и самообновления; `tools/pack.rb` выравнивает в нём версию и кладёт копию в `.rbz`.

## [0.3.0] — 2026-10-09

### Changed
- Переход на схему версионирования 0.x по решению пользователя: версия сброшена с 1.3.0 на 0.3.0. Правила версионирования зафиксированы в этом файле.

### Fixed
- Pack-скрипт исключает dev-файлы из `.rbz` без учёта регистра букв (коммит a470f55).
